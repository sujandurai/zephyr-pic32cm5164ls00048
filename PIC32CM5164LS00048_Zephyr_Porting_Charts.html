Hardware Architecture & MCU Peripheral Map Microchip PIC32CM5164LS00048 (48-Pin)

ARM Cortex-M23 Core

• 48 MHz Max CPU Clock (FDPLL96M)

• ARMv8-M Baseline ISA

• 2-Bit NVIC Priority (71 IRQ Lines)

• Hardware SysTick Timer

System Memory Subsystem

• 512 KB Embedded Flash (NVMCTRL)

• 64 KB High-Speed SRAM @ 0x20000000

• Flash 2 Wait States @ PL2 48 MHz

• Assembly ECC Zero-Init in soc_reset_hook()

Clock Control (OSCCTRL & GCLK)

• Internal 16 MHz RC Oscillator (OSC16M)

• GCLK1: 1.0 MHz Reference Clock

• FDPLL96M: 48.0 MHz Multiplier

• GCLK0: 48.0 MHz Core System Clock

6x SERCOM Interfaces

• SERCOM0 - SERCOM5 (0x42000400 - 0x42001800)

• Configurable UART / SPI / I2C

• SERCOM0: Virtual COM Port (PA22 TX, PA23 RX)

• 115200 Baud, 8-N-1 Hardware Support

Port G1 GPIO Controller

• PORTA (32 Pins) @ 0x40003000

• PORTB (32 Pins) @ 0x40003080

• Direct reuse of Zephyr gpio_sam0.c

• Atomic DIRSET, OUTTGL, IN registers

Analog & Timers

• TC0 - TC2 16/32-Bit Counter Timers

• TCC0 - TCC3 PWM Capture Timers

• 12-Bit Differential ADC, 10-Bit DAC

• 12-Channel DMA Controller (DMAC)

Step 1: Declare in SoC DTSI (pic32cm5164ls00048.dtsi)

soc {
    sercom0: sercom@42000400 {
        compatible = "atmel,sam0-uart";
        reg = <0x42000400 0x40>;
        interrupts = <31 0>, <32 0>, <33 0>, <34 0>;
        status = "disabled";
    };
};

Step 3: Enable in Kconfig (prj.conf / _defconfig)

CONFIG_SERIAL=y
CONFIG_CONSOLE=y
CONFIG_UART_CONSOLE=y

Step 2: Enable in Board DTS (pic32cm_ls00_cnano.dts)

/ {
    chosen {
        zephyr,console = &sercom0;
        zephyr,shell-uart = &sercom0;
    };
};

&sercom0 {
    status = "okay";
    current-speed = <115200>;
    rxpo = <1>; /* PA23 is PAD1 (RX) */
    txpo = <0>; /* PA22 is PAD0 (TX) */
};

Step 4: Application C Code (main.c)

#include <zephyr/kernel.h>
#include <zephyr/sys/printk.h>

int main(void) {
    printk("Hello PIC32CM5164LS00048 UART!\n");
    return 0;
}
